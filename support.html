الدعم الفني لـ EgCenterMgmt

معلومات عملية للتثبيت والتشغيل وتشخيص المشكلات الشائعة، مع قنوات تواصل مباشرة عبر الاتصال وWhatsApp والبريد الإلكتروني.

Windows Desktopدعم فني مباشرإيجي سنتر | EgCenter
01

التثبيت والتشغيل

إذا تم تثبيت التطبيق عبر Microsoft Store، حدّث Windows وMicrosoft Store ثم شغّل EgCenterMgmt من قائمة Start.

02

الدخول للحساب

إذا كانت المشكلة مرتبطة بحساب أو صلاحية، تواصل مع مسؤول النظام داخل المركز أو أرسل تفاصيل المشكلة للدعم.

03

البيانات

بيانات التشغيل تديرها المؤسسة المستخدمة للتطبيق، ويجب التعامل مع النسخ الاحتياطية وسياسات الاحتفاظ وفق إعداد المؤسسة.

04

الخصوصية

راجع سياسة الخصوصية الرسمية لمعرفة كيفية التعامل مع البيانات.

قبل التواصل مع الدعم

  • أغلق التطبيق وافتحه من جديد ثم جرّب تنفيذ نفس الخطوة.
  • اكتب اسم الشاشة والخطوة التي نفذتها ونص رسالة الخطأ كما ظهر.
  • اذكر إصدار Windows وأي تغيير تم قبل ظهور المشكلة.
  • إذا كانت المشكلة مرتبطة بالصلاحيات، حدّد المستخدم أو الدور والمهمة المطلوبة.
  • لا ترسل كلمات المرور أو أي بيانات حساسة.

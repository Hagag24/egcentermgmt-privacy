EgCenterMgmt Support

Help for installation, access and day-to-day use of the EgCenterMgmt desktop management application.

🖥️

Installation & launch

If the application was installed from Microsoft Store, keep Windows and Microsoft Store up to date and launch EgCenterMgmt from the Start menu.

🔑

Account access

If your organization manages user accounts, contact your administrator for access, password reset or permission changes.

🗄️

Data & database

Business data is managed by the organization operating the application. Backup and retention procedures should follow the organization's own policies.

🛡️

Privacy

For information about data processing and privacy practices, review the official Privacy Policy.

Before contacting support

  • Confirm Windows is fully updated.
  • Restart the application and try the action again.
  • Record the exact screen, action and error message if one appears.
  • If the issue concerns permissions or organization data, identify the affected user role and workflow.

Contact support

Email: mohamed.dev.eg@gmail.com
When possible, include the application name “EgCenterMgmt”, your Windows version, and a short description of the issue.

Support scope

Support covers product access, installation guidance, application behavior and general technical assistance. Organization-specific data policies, account permissions and operational decisions remain under the control of the organization using the application.

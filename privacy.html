سياسة الخصوصية

توضح هذه السياسة كيفية تعامل EgCenterMgmt مع المعلومات عند استخدام التطبيق بواسطة الجهات والمستخدمين المصرح لهم، وما الذي يظل تحت تحكم المؤسسة التي تستخدم النظام.

آخر تحديث: 19 أغسطس 2026EgCenterMgmtPublisher: Hagag
ملخص: يختلف نوع البيانات التي يعالجها التطبيق بحسب طريقة إعداد المؤسسة للنظام واستخدامها له. لا يستخدم EgCenterMgmt المعلومات الشخصية لأغراض إعلانية ولا يبيعها.

1. المعلومات التي يعالجها التطبيق

قد يعالج EgCenterMgmt المعلومات التي يُدخلها المستخدمون المصرح لهم ضمن الأعمال الإدارية والتشغيلية المعتادة، وقد تشمل الأسماء وبيانات الحسابات ومعلومات التواصل وسجلات الطلاب والعملاء والموظفين والحضور والتشغيل والسجلات الإدارية المرتبطة بالمدفوعات أو المعاملات المالية وأي معلومات أخرى تدخلها المؤسسة أثناء استخدام النظام.

2. كيفية استخدام المعلومات

تُستخدم المعلومات فقط لتقديم وظائف التطبيق الإدارية والتشغيلية، بما في ذلك إدارة السجلات والمستخدمين والمجموعات والحضور والاشتراكات والمدفوعات والحسابات والتقارير والخدمات المرتبطة بها. لا يستخدم التطبيق المعلومات الشخصية لأغراض الإعلانات.

3. تخزين البيانات والتحكم فيها

قد يتم تخزين بيانات التطبيق في قواعد بيانات أو أنظمة تخزين تقوم المؤسسة المستخدمة للتطبيق بإعدادها أو تشغيلها. وتحدد المؤسسة مدة الاحتفاظ بالبيانات وفق احتياجاتها التشغيلية والالتزامات القانونية المطبقة عليها، كما تتحكم في حسابات المستخدمين والصلاحيات وسياسات الوصول إلى البيانات.

4. مشاركة البيانات

لا يبيع EgCenterMgmt المعلومات الشخصية. وقد تكون المعلومات متاحة للمستخدمين المصرح لهم داخل المؤسسة، كما قد يتم تبادلها مع خدمات أو أنظمة مرتبطة فقط عندما يكون ذلك ضروريًا لتشغيل التطبيق أو تقديم خدمة مطلوبة.

5. الأمان

تُستخدم إجراءات تقنية وتنظيمية معقولة للمساعدة في حماية المعلومات من الوصول غير المصرح به أو التعديل أو الإفصاح أو الفقد. ويعتمد الوصول إلى وظائف التطبيق وبياناته على الحسابات والأدوار والصلاحيات التي تضبطها المؤسسة.

6. الاتصال بالإنترنت

قد يستخدم التطبيق اتصالًا بالإنترنت للتواصل مع خدمات خلفية أو واجهات API أو خدمات مصادقة أو ترخيص أو خدمات Microsoft Store اللازمة للتثبيت أو التحديث أو بعض وظائف التشغيل، بحسب إعداد ونمط استخدام النظام.

7. حقوق المستخدمين وطلبات البيانات

إذا أراد المستخدم الوصول إلى معلوماته الشخصية أو تصحيحها أو تحديثها أو طلب حذفها، فعليه التواصل مع المؤسسة التي تدير نسخة النظام المستخدمة لديه أو التواصل مع دعم التطبيق عند الحاجة. ويتم التعامل مع الطلبات وفق القوانين المطبقة وسياسات المؤسسة.

8. معلومات الأطفال والقُصّر

EgCenterMgmt نظام إداري وتشغيلي للمراكز التعليمية. يجب إدخال وإدارة أي معلومات تتعلق بالقُصّر فقط بواسطة جهات ومستخدمين مصرح لهم وبما يتوافق مع القوانين والسياسات المطبقة على المؤسسة المستخدمة للنظام.

9. التعديلات على سياسة الخصوصية

قد يتم تحديث سياسة الخصوصية عندما تتغير وظائف التطبيق أو ممارسات معالجة البيانات أو المتطلبات القانونية. وستظل أحدث نسخة منشورة متاحة من خلال هذه الصفحة.
